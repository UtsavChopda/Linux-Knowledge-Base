# Linux Enterprise Administration & Automation Lab

A hands-on Linux administration project built on an Ubuntu Server VM. This project complements the Linux Knowledge Base by turning concepts into repeatable labs, scripts, evidence, troubleshooting notes, and a final administration toolkit.

## Status

Phase 0 — Project initialized.

## Project Roadmap

- [ ] Lab environment and baseline
- [ ] Filesystem and core commands
- [ ] Users and groups
- [ ] Permissions and ACLs
- [ ] Package management
- [ ] Processes and resource management
- [ ] systemd and services
- [ ] Networking
- [ ] SSH administration
- [ ] Storage and LVM
- [ ] Backup and recovery
- [ ] Bash scripting
- [ ] cron automation
- [ ] Health checks
- [ ] Final Linux Administration Toolkit
