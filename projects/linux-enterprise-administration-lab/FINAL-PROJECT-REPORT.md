# Final Project Report — Linux Enterprise Administration & Automation Lab

## Executive Summary
This project is a portfolio-grade Linux administration lab designed to demonstrate server build, configuration, identity management, permissions, software management, process/service administration, networking, SSH, storage, backup/recovery, Bash automation, monitoring, troubleshooting and defensive hardening.

## Objectives
1. Build a repeatable Linux server lab.
2. Demonstrate day-to-day administration.
3. Demonstrate structured troubleshooting.
4. Automate repetitive administration with Bash.
5. Prove backup and recovery.
6. Apply responsible hardening.
7. Produce interview-ready evidence.

## Architecture
Windows host → VirtualBox/VMware → Ubuntu Server LTS. NAT is used initially; additional isolated networking can be introduced for multi-VM scenarios.

## Methodology
For each module: learn → configure → test → verify → troubleshoot → document → capture evidence.

## Evidence Policy
Only real VM outputs are accepted. Screenshots must not contain passwords, private keys, tokens or other secrets.
