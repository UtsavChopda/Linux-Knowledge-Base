# 🚀 29 — Linux Projects

These projects combine administration, scripting and Blue Team skills.

## Project 01 — System Information Tool
Collect host, kernel, uptime, CPU, memory, disk, filesystem and network information. Output clean Markdown/JSON.

## Project 02 — User Audit Tool
Report users, groups, UID 0 accounts, login shells, home directories and sudo access. Read-only.

## Project 03 — SIEM Log Analyzer
Parse supplied authentication logs, identify failed/successful logins, source IPs, usernames and suspicious bursts.

## Project 04 — Failed SSH Login Detector
Create a configurable detector for repeated failures. Include threshold, time window, source and username, while minimizing duplicate alerts.

## Project 05 — Process Monitor
Periodically collect process and resource information and highlight changes from baseline.

## Project 06 — File Integrity Monitor
Maintain a protected baseline of selected files and compare hashes periodically. Clearly separate change detection from attribution.

## Project 07 — Linux Security Auditor
Combine account, SSH, services, packages, firewall, mounts, scheduled tasks and logging checks into one report.

## Project 08 — SOC Investigation Toolkit
Collect read-only evidence for host identity, users, processes, sockets, routes, services, timers, SSH metadata and selected logs.

## Project 09 — Linux Network Auditor
Inventory interfaces, routes, DNS configuration, neighbors and listeners. Explain expected vs unexpected exposure.

## Project 10 — Linux Health Monitor
Track CPU, memory, disk, inode, service and network health with thresholds and clear remediation guidance.

## Project Quality Standard
Every project should include:
- README and architecture diagram;
- requirements;
- installation/use;
- safe defaults;
- sample output;
- error handling;
- test cases;
- security considerations;
- limitations;
- future improvements.

## Portfolio Tip
Prefer projects that demonstrate **why** a result matters, not just commands. Show sample investigation reports and explain design decisions.
